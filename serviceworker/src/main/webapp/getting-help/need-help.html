Help within Sakai

Detailed help documentation can be accessed by clicking the Help icon at the top of Sakai.

Request Support

Do you need help with Sakai? You can contact the Sakai Support Team by emailing sakai@plu.edu, calling 253-535-7525, or making a PLU Help Desk service request (requires a PLU ePass account).

To access Sakai support resources from any Sakai page when you are logged into Sakai, click the Quick Links icon in the top navigation bar and then select Sakai Help & Support.
